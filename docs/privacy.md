# Privacy

NetLogo Browser Lab collects no analytics by default.

The app stores local preferences in IndexedDB on the user's device. It does not send model selections, run settings, or browser capability details to a server.

External requests in v1:

- Static app and data assets from https://baditaflorin.github.io/netlogo-browser-lab/
- Optional CheerpJ runtime from https://cjrtnc.leaningtech.com/ after the user initializes the Java runtime
- Optional outbound links to https://github.com/baditaflorin/netlogo-browser-lab and https://www.paypal.com/paypalme/florinbadita
